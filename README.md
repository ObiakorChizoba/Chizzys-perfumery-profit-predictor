# Chizzy's Perfumery Profit Predictor

## 📌 Overview
This project is a data-driven web application designed to help small business owners analyze costs, pricing, and profitability across different product variations.

## 🚨 Problem
Many small-scale perfume sellers struggle to accurately track expenses and calculate profit margins, leading to poor pricing decisions and reduced profitability.

## 💡 Solution
Developed an interactive web application using Streamlit that automates cost calculation and profit analysis.

## 🔍 Key Features
- Calculates total cost (including bottle, fragrance, and labeling)
- Determines profit margins across different pricing strategies
- Provides interactive data visualizations (bar charts, pie charts)
- Allows comparison of different product sizes
- Generates structured outputs for decision-making

## 🧠 Analytical Approach
- Applied data analysis techniques to evaluate cost vs profit relationships
- Interpreted results to identify optimal pricing strategies
- Ensured consistency and accuracy across multiple input scenarios

## 🛠️ Tech Stack
- Python
- Streamlit
- Pandas
- Matplotlib

## 📊 Outcome
This project improves business decision-making by providing clear insights into pricing and profitability while reducing manual calculation errors.

- Demonstrates structured reasoning and analytical thinking
- Involves evaluating outputs and interpreting results
- Builds skills in identifying patterns and inconsistencies
